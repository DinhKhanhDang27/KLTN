========================================================
Standard AXI Protocols (Reference)
========================================================

Giao thức Handshake chung (Global Handshake):
- Tất cả các kênh của giao thức AXI đều sử dụng cơ chế bắt tay VALID / READY:
  + Nguồn (Master/Source) phát tín hiệu VALID khi địa chỉ, dữ liệu hoặc tín hiệu điều khiển đã hợp lệ.
  + Đích (Slave/Destination) phát tín hiệu READY khi có thể tiếp nhận thông tin.
  + Dữ liệu thực sự được truyền đi (transfer) khi cả VALID và READY cùng ở mức HIGH (1) tại sườn lên của xung nhịp (Clock).

--------------------------------------------------------
1. AXI4-Lite (5 Kênh)
- Số kênh: 5 (Write Address, Write Data, Write Response, Read Address, Read Data)
- Ứng dụng: Giao tiếp thanh ghi điều khiển cơ bản, không hỗ trợ burst.
--------------------------------------------------------
  -- Global Signals
  input         aclk
  input         aresetn

  -- Write Address Channel (AW)
  input  [31:0] awaddr    // Địa chỉ ghi
  input  [2:0]  awprot    // Quyền truy cập/bảo vệ
  input         awvalid   // Địa chỉ ghi hợp lệ
  output        awready   // Slave sẵn sàng nhận địa chỉ ghi

  -- Write Data Channel (W)
  input  [31:0] wdata     // Dữ liệu ghi
  input  [3:0]  wstrb     // Byte enable (chỉ định byte hợp lệ trong wdata)
  input         wvalid    // Dữ liệu ghi hợp lệ
  output        wready    // Slave sẵn sàng nhận dữ liệu ghi

  -- Write Response Channel (B)
  output [1:0]  bresp     // Phản hồi trạng thái ghi (OKAY, EXOKAY, SLVERR, DECERR)
  output        bvalid    // Phản hồi ghi hợp lệ
  input         bready    // Master sẵn sàng nhận phản hồi ghi

  -- Read Address Channel (AR)
  input  [31:0] araddr    // Địa chỉ đọc
  input  [2:0]  arprot    // Quyền truy cập/bảo vệ
  input         arvalid   // Địa chỉ đọc hợp lệ
  output        arready   // Slave sẵn sàng nhận địa chỉ đọc

  -- Read Data Channel (R)
  output [31:0] rdata     // Dữ liệu đọc
  output [1:0]  rresp     // Phản hồi trạng thái đọc
  output        rvalid    // Dữ liệu đọc hợp lệ
  input         rready    // Master sẵn sàng nhận dữ liệu đọc

--------------------------------------------------------
2. AXI4 Full (5 Kênh - Hỗ trợ Burst)
- Số kênh: 5
- Ứng dụng: Truyền dữ liệu lớn, bộ nhớ (RAM, DMA), hỗ trợ truyền Burst (truyền nhiều data với 1 address).
- Bao gồm các tín hiệu của AXI4-Lite cộng thêm các tín hiệu sau:
--------------------------------------------------------
  -- Write Address Channel (AW) bổ sung
  input  [7:0]  awlen     // Độ dài burst (số lượng data transfer trong 1 burst)
  input  [2:0]  awsize    // Kích thước của mỗi transfer (1, 2, 4, 8... bytes)
  input  [1:0]  awburst   // Loại burst (FIXED, INCR, WRAP)
  input         awlock    // Khóa truy cập (độc quyền)
  input  [3:0]  awcache   // Thuộc tính bộ nhớ (Cacheable, Bufferable...)
  input  [3:0]  awqos     // Quality of Service
  input  [3:0]  awregion  // Định danh vùng bộ nhớ
  input  [x:0]  awid      // ID của giao dịch ghi

  -- Write Data Channel (W) bổ sung
  input         wlast     // Cờ đánh dấu Data transfer cuối cùng của burst

  -- Write Response Channel (B) bổ sung
  output [x:0]  bid       // ID phản hồi (khớp với awid)

  -- Read Address Channel (AR) bổ sung
  input  [7:0]  arlen     // Độ dài burst đọc
  input  [2:0]  arsize    // Kích thước của mỗi transfer
  input  [1:0]  arburst   // Loại burst (FIXED, INCR, WRAP)
  input         arlock    // Khóa truy cập
  input  [3:0]  arcache   // Thuộc tính bộ nhớ
  input  [3:0]  arqos     // Quality of Service
  input  [3:0]  arregion  // Định danh vùng bộ nhớ
  input  [x:0]  arid      // ID của giao dịch đọc

  -- Read Data Channel (R) bổ sung
  output        rlast     // Cờ đánh dấu Data transfer cuối cùng của burst
  output [x:0]  rid       // ID dữ liệu đọc (khớp với arid)

--------------------------------------------------------
3. AXI4-Stream (1 Kênh Dữ liệu)
- Số kênh: 1 Kênh truyền luồng (Data Stream) theo 1 chiều từ Master sang Slave.
- Ứng dụng: Xử lý DSP, Video, Network packet, truyền dữ liệu tốc độ cao không cần địa chỉ.
- Handshake: VALID / READY
--------------------------------------------------------
  input         aclk
  input         aresetn
  
  output [x:0]  tdata     // Dữ liệu chính (độ rộng x thường là bội của 8)
  output        tvalid    // Tín hiệu hợp lệ của tdata (từ Master)
  input         tready    // Tín hiệu sẵn sàng nhận (từ Slave)
  
  output        tlast     // Đánh dấu Transfer/Byte cuối cùng của 1 packet
  output [y:0]  tkeep     // Byte qualifier: chỉ định các byte nào chứa dữ liệu thật
  output [y:0]  tstrb     // Byte qualifier: dùng cho null bytes
  output [z:0]  tid       // Stream ID: phân biệt các luồng dữ liệu
  output [w:0]  tdest     // Routing ID: đích đến của dữ liệu
  output [v:0]  tuser     // Tín hiệu tuỳ chỉnh do user định nghĩa
