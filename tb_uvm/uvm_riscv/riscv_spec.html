RISC-V (RV32I) + SHA256/SHA512 SoC Verification Specification

Overview: This document serves as the target specification for UVM verification of the custom RISC-V SoC. The design implements the base RV32I instruction set, integrated via Qsys (Platform Designer).

1. RV32I Base Integer Instruction Set Spec

The core is a 32-bit architecture with 32 integer registers (x0-x31) of 32 bits each. x0 is hardwired to zero. The PC is also 32 bits. Verification must ensure standard compliance with the RISC-V Unprivileged ISA.

2. Standard RISC-V Cryptography Extension (Zknh) Reference

For standard compliance or future ISA migrations, verify the differences against the official RISC-V Scalar Cryptography Extension (Zknh). Unlike the custom accelerator in this project, Zknh provides specific ALU instructions to accelerate hash rounds without stateful peripheral blocks.
