UVM RISC-V Speedrun

Bạn đã biết RISC-V — bộ lab này dùng core làm “bãi tập” để luyện UVM công nghiệp: từ interface/clocking, factory, config_db, phases, TLM, sequence, scoreboard, coverage, RAL cho tới callback, regression. Mỗi lab: code đầy đủ, vòng code → change → compare, câu hỏi phỏng vấn có ví dụ và 8 bài tập rèn tay.
